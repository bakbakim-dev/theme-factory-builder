> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a repeatable local SaaS foundation for Whipify projects, conversion jobs, site analysis, QA reporting, and dashboard readiness summaries.

**Architecture:** Keep SaaS product logic in focused TypeScript modules under `utils/saas-core/` and mount a standalone dashboard panel in `App.tsx`. Existing converter lanes remain unchanged except for reading their names/status in the SaaS report model.

**Tech Stack:** Vite, React, TypeScript, Node regression scripts, localStorage-compatible project repository.
